## rgctl v0.4.21

All-dimension supremacy sprint: single-pass AST engine, bi-directional coverage gates, C3 MRO, lazy CFG/PDG, Fast-Leiden, FileFacts + `watch`, two-tier polyglot (23 Tier-1 + 35+ Tier-2), framework routes/DI, and hot-path / CI performance gates.

OpenSpec: `openspec/changes/rgctl-all-dimension-supremacy/` (§0–§10).

```bash
rgctl --version   # 0.4.21

# Re-discover after upgrade (graph shape / IDs / language coverage can change)
rm -rf .rgctl && rgctl discover . -v

# Live incremental (FileFacts + watch)
rgctl watch .

# Lazy CFG / slice without prior --with-cfg
rgctl -f json slice <symbol> --criterion <var>:<line>

# Optional overlays
rgctl discover . --with-git
rgctl merge <other-repo>   # park-and-resolve across sessions
```

## Highlights

### Bi-directional AST coverage contract (§1)

- `LanguagePlugin::declared_ast_handlers` + `check_plugin_manifest_sync()` keep `{lang}-ast-coverage.json` and plugin dispatch tables in lockstep.
- `AstCoverageTracker` fails tests when a non-`Skip` / non-`Literal` kind has zero hit assertions.
- CI: `RGCTL_AST_COVERAGE_STRICT=1` (and tracked runtime coverage gates) fail the build on grammar ↔ handler drift.

### Single-pass `u16` jump-table & scope-stack AST engine (§2)

- Thread-local `parse_with_pool` / `with_thread_local_parser` (no per-file `Parser::new()` on the extract hot path).
- `KindDispatchTable` (`O(1)` `kind_id` dispatch) + `ScopeStack` single iterative DFS.
- Complexity (cyclomatic / cognitive / nesting / returns / LOC) folded into the active function frame — no per-function re-parse.
- Target: ≥30% extract wall vs multi-pass on Tier-1 samples (`benches/parsing`).

### Deep AST / call / field extraction parity (§3)

- Deeper call forms and members across Rust, Python, TS/JS, C/C++, plus structured field/member parity for Go, Java, Kotlin, C#, Ruby, PHP.
- Manifest promotions for high-value kinds previously marked `Skip` (match/with/type aliases, scoped paths, arrows, namespaces, range-for, etc.).

### Cross-language C3 MRO & inheritance (§4)

- Dense C3 linearization (`mro.rs`) with language fallbacks (C++ leftmost-base, Java/C#/Kotlin/TS class-over-interface, Ruby reverse include, Rust inherent-over-trait).
- Emits `EdgeType::Overrides`; inherited `self` / `this` / `super` / receiver calls resolve via MRO when the subtype does not override.

### Lazy CFG/PDG archive & slicer precision (§5)

- `cfg_pdg.bin` v3 sorted TOC: `O(1)` open, binary-search + zero-copy per-function records.
- On-demand CFG/PDG for `slice` / `taint` / `cpg` when archive missing (no mandatory `discover --with-cfg`).
- Lexical block-scope shadow IDs (`x#scope_id`); C/C++ `#if 0` / `#if false` dead-branch pruning.
- Word-level BitSet reaching defs; optional `--scip <path.scip>` overlay.

### Fast-Leiden & production-aware PageRank (§6)

- CSR queue-based Fast-Leiden (hub strip + importance tie-break) replaces Label Propagation as the default community detector.
- Faster `FastPageRank` (parallel contrib / dangling mass); `NodeRole` filters Test / ExternalIntrinsic by default (`--include-tests` to opt in).
- Parallel sampled betweenness + dense SCC index; Gate A linux cold discover baseline tightened to **75 s** / **2.8M** nodes.

### FileFacts cache & `rgctl watch` (§7)

- Content-addressed `.rgctl/cache/facts.bin` keyed by `(BLAKE3(bytes), grammar ABI, AST-manifest fingerprint)`.
- Unchanged files skip Tree-sitter on warm `discover` / `update`; cold / `--no-incremental` / >10k-file first runs bypass cache population.
- `rgctl watch`: notify + 25 ms debounce, atomic mmap swap, sub-100 ms single-file incremental target.

### Two-tier polyglot + domain passes (§8)

- **Tier-1 custom** (+8): Swift, Scala, Dart, Elixir, Lua, Bash, SQL, HCL/Terraform (15 → 23 deep plugins with AST coverage + CFG).
- **Tier-2 `tags.scm`**: declarative query engine (`handler = "queries"`) for 35+ packs (Zig, Solidity, OCaml, Haskell, Clojure, R, Fortran, Julia, Vue/Svelte, GDScript, ObjC, Verilog, Nix, Protobuf, TOML/YAML/JSON, HTML/CSS, GraphQL/Prisma, Elm, Erlang/Gleam/F#, Scheme/Racket/Elisp, D/Odin/CUDA/GLSL/VHDL, CMake/Make/Starlark/PowerShell, …).
- Framework catalog: `ExposesRoute` / `Injects` + semantic tags/vocab (FastAPI/Django/Flask, Express/Nest, Spring/Quarkus, Axum/Actix, Gin/Fx, ASP.NET, Rails, Laravel, Ktor/Dagger, …).
- Optional `--with-git` (`CoChangesWith` / churn); `rgctl merge` park-and-resolve across repos.

### End-to-end correctness & CI gates (§9)

- Golden / QE coverage for AST contract, single-pass complexity parity, N-way graph determinism, MRO/DI/routes, CFG/PDG TOC + shadowing/taint, Leiden connectivity + centrality roles, FactsCache equivalence.
- CI (maintainer `ci` label / `workflow_dispatch`): AST track, MRO/DI, slicing/taint, community/centrality audits, incremental integration, columnar zero-cold-touch, scale perf, blast-radius perf.

### Pure performance engineering (§10)

- Ingest hot-path discipline: parser pool on markdown, scratch reuse in relation/MRO resolution, verified spill/`SymbolPass1Prep` / single-hash tracker path.
- Structured query / inventory: hot-column scans — cold_ext only when properties required.
- Expanded `columnar_zero_cold_touch_gate` (FastPageRank + Fast-Leiden + hot name/type scan → `cold_ext == 0`).
- Parallel thresholds (PageRank / SampledBetweenness ≥ 4 096 nodes); bench smoke + centrality scale gates; `$GITHUB_STEP_SUMMARY` via `scripts/generate-ci-gate-summary.py` + artifact `.rgctl-ci-gate-report.json`.
- Cold profile notes: [profile.md](../internal/profile.md). Reference cold linux discover ~**48–75 s** depending on tree fullness (Gate A envelope **75 s** +10%).

### Analysis hot-path prerequisites (§0)

- Lazy `FlatGraphIndex` out-adjacency; HyperBall self-ball fix; semantic diffusion neighbor hoist; blast-radius cache JSON columns restored.

## Breaking / migration notes

| Change | Action |
|--------|--------|
| Single-pass extract + deeper AST / MRO / Overrides | Delete `.rgctl/` and re-run `discover` (node/edge sets and some UUIDs can change) |
| Fast-Leiden default communities | Re-run community / dashboard exports; Label Propagation no longer the default partition |
| PageRank `NodeRole` filtering | Hotspot lists drop tests/intrinsics by default; pass `--include-tests` when needed |
| FileFacts / watch | Expect `.rgctl/cache/facts.bin`; corrupt `.tmp` is recovered; cold large repos may skip populate |
| New Tier-1 / Tier-2 languages | Opt-in via `-l` / registry; re-discover to index new extensions |
| Framework `ExposesRoute` / `Injects` | New edge types in snapshots; agents/schemas should allow them |
| CFG/PDG TOC v3 + lazy append | Older `cfg_pdg.bin` may need rebuild (`discover --with-cfg` or first lazy slice) |
| SCIP / `--with-git` / `merge` | Optional; no change if unused |
| AST coverage strict CI | Contributors: keep `*-ast-coverage.json` in sync when bumping grammars or handlers |
