## rgctl v0.4.20

Deterministic cold discover, non-destructive PR review delta heads, faster `--with-cfg` / `--full`, richer agent/human CLI UX, clone detection, and fact-checked docs.

```bash
rgctl --version   # 0.4.20

# Deterministic graph (re-discover after upgrade)
rgctl discover . -l java --with-cfg

# Safer review head synthesis (scratch under .rgctl/synth-head/)
rgctl -f json review paths --synthetic-head worktree
rgctl -f json review export --policy-file policy.json

# Agent-friendly errors + symbol disambiguation
rgctl -f json inspect checkout --class OrderService cfg
rgctl -f json status   # schema_version 3 + capabilities

# Clone detection (query-time; not in the snapshot)
rgctl -f json clones --mode exact --min-loc 5
```

## Highlights

### Discover graph determinism ([#125](https://github.com/sshaaf/rgctl/issues/125))

Cold `discover` edge identity is stable under parallel extract:

- Pass-2 applies extraction tails in **path-sorted** order.
- `Calls` resolve only to `Function` nodes.
- Bare / field-like `References` do not invent Class external stubs (typed refs still can).
- Stable node IDs prefer **qualified name**; `start_line` is not hashed.
- Diff/review hot paths read QN via a zero-alloc columnar helper.

**Re-discover required** after upgrade — node UUIDs and edge sets can change vs pre-fix indexes.

### Review / pr-check delta head ([#124](https://github.com/sshaaf/rgctl/issues/124))

Default head synthesis is **non-destructive**:

- Synthesized head lands under `.rgctl/synth-head/` (not the live snapshot).
- Compaction drops base edges whose **source** file was invalidated.
- `--synthetic-head worktree` can use the live session as base.
- `review export` reuses prepared base/head snapshots.

Also: `rgctl review export` composes one versioned review artifact; slice resolves the enclosing function from the criterion line; JS/TS destructuring patterns bind names for more accurate slices.

### Faster `--with-cfg` / `--full`

- Single-pass per file: CFG/PDG, locals, field writes, optional AST skeletons.
- Worker-side bincode + buffered archive merge.
- `--full` Stage 2 reuses basic analytics when digests match.
- Reference cold walls: node `--with-cfg` ~**4.8 s**; metasfresh `--full` ~**25.7 s**. Details: [profile.md](../internal/profile.md).

### CFG empty-block contraction ([#121](https://github.com/sshaaf/rgctl/issues/121))

- Lazy `if` / `unless` allocation; post-prune `contract_empty_blocks`.
- Restores PDG control dependencies across early-return guards.

### Agent & human CLI UX

- JSON error envelope (`ok: false`, `error_code`, candidates / suggestions / `recovery_command`).
- `--file` / `--class` / `--line` on inspect / cpg / blast-radius; `Class::method` for slice / cpg flows.
- `status` `schema_version: 3` with capabilities unlock hints.
- TTY-friendly query rows and inspect/metrics summaries; enriched metrics `top[]`.
- Self-contained skills; **`rgctl-review`** + `/rgctl:review` (session `REVIEW_REPORT.md`, no forge posting).

### Clone detection ([#37](https://github.com/sshaaf/rgctl/issues/37))

`rgctl clones` — exact / bloom / fragment (SESE + 1-WL). Query-time sidecars only; Gate A unchanged. Guide: [Clone detection](https://rgctl.io/docs/guides/clone-detection/).

### Build / CI ([#123](https://github.com/sshaaf/rgctl/issues/123))

- Track `Cargo.lock`; pin `ort = 2.0.0-rc.13`.
- Always-on PR job: `cargo check --locked --bin rgctl`.

### Testing, docs, website

- Graph invariants, determinism / stable-key QE, ecommerce correctness, e2e contracts, columnar / scale gates.
- [Language testing guide](../language-testing-guide.md); fact-checked guides + `docs_guides_cli_fact_check` / `verify-docs-commands.sh`.
- Website SEO: sitemap, robots, llms.txt, per-doc meta, docs sidebar IA.
- Dashboard polish: defect fixes, restored phase-gate scripts, compiling test target.

## Breaking / migration notes

| Change | Action |
|--------|--------|
| Deterministic IDs / Calls+References ([#125](https://github.com/sshaaf/rgctl/issues/125)) | Delete `.rgctl/` and re-run `discover` |
| Review synth head ([#124](https://github.com/sshaaf/rgctl/issues/124)) | Expect `.rgctl/synth-head/`; live snapshot no longer overwritten by default delta |
| `status` schema | Agents: accept `schema_version: 3` + `capabilities` |
| Skill / review pack | `rgctl install --skill --tools … --force` to refresh on disk |
| Fresh clones ([#123](https://github.com/sshaaf/rgctl/issues/123)) | Use committed `Cargo.lock` (`cargo build --locked`) |
